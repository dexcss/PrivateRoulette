# Private Roulette

Fully self-hosted, whitelisted dealer roulette for FFXIV — **no third-party
services**. Three pieces, all yours:

| Piece | Where | What |
|---|---|---|
| **Plugin** (this repo) | Dalamud, `/pr` | Dealer console: game control, dice capture, announcements, spin verification |
| **Backend** (`server/`) | Your Cloudflare Worker (free) | Authoritative game state, provable-fair spins, ledger, WebSockets |
| **Web client** (`web/`) | Your GitHub Pages | Player betting: animated wheel, full board, chat, history |

Players bet from a browser at your Pages URL (`#/{gameId}/{playerKey}` links
are handed out by the plugin); the dealer rolls `/random` in-game; every spin
is verifiable: `result = uint(sha256("{dice}:{control}")) % 37`.

**Access control:** only whitelisted characters can run the plugin, and only
your dealer token unlocks the backend. Player seats are keyed by per-player
links generated by the plugin.

- Plugin: build with `dotnet build -c Release`; releases are tagged `v*`.
- Backend: see `server/README.md` (5-minute one-time setup).
- Web: served automatically by the Pages workflow on push to `main`.
